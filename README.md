# kallistesoft.ca

Static site for Kallistesoft, hosted on GitHub Pages at https://kallistesoft.ca.

- French at `/`, English at `/en/`. Every page exists in both languages: `block-daily/` ↔ `en/block-daily/`, `confidentialite/` ↔ `en/privacy/`.
- Plain HTML and one stylesheet (`assets/style.css`), with no build step. Push to `main` to publish.
- Preview locally: `python3 -m http.server` and open http://localhost:8000.
